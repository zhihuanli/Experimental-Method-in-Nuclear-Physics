作业 1.1：用射程和阻止本领数据计算 Bragg 曲线

带电粒子在物质中连续损失能量。粒子减速后，单位路程内的平均能量损失通常在射程末端附近明显增大，形成 Bragg 峰。本作业使用 LISE++ 给出的射程和阻止本领数据，计算质子和 \(^{12}\mathrm{C}\) 在水中的平均能损曲线，并比较不同数值方法。

这里采用连续慢化近似（continuous slowing-down approximation, CSDA），假定粒子近似沿直线运动，并忽略能损涨落、射程涨落和核反应。所得曲线表示单个粒子的平均局部能量损失，不包含束流衰减、\(^{12}\mathrm{C}\) 碎裂和次级粒子输运，因而不是完整的实验深度剂量分布。

作业在 Jupyter 中完成。C++ 选择 ROOT C++ 内核，Python 选择 Python 3 内核并使用 PyROOT。开始前应完成 ROOT Tutorial I（C++）或 ROOT Tutorial I（PyROOT），并阅读 LISE++ 射程和能损教程。

1. 计算任务

分别对质子和 \(^{12}\mathrm{C}\) 完成以下计算：

  1. 取靶材料为液态水，密度为 \(1.0\ \mathrm{g/cm^3}\)，获得射程 \(R(\varepsilon)\) 和阻止本领 \(S(\varepsilon)\) 数据。其中

    \[ \varepsilon=\frac{E}{A},\qquad S(\varepsilon)=-\frac{dE}{dx}>0. \]

    \(E\) 是粒子的总动能，\(A\) 是质量数。LISE++ 输出的 \(S\) 是整颗离子的总能量损失率，不能再乘以 \(A\)。

  2. 求出使 CSDA 射程为

    \[ R_{\mathrm{target}}=127\ \mathrm{mm} \]

    时的入射能量。分别给出 \(\varepsilon_0=E_0/A\) 和总能量 \(E_0\)，并用射程曲线反查，检验结果与 127 mm 的差别。

  3. 构造

    \[ S(x)=S\!\left(\frac{E(x)}{A}\right) \]

    并将质子和 \(^{12}\mathrm{C}\) 的 Bragg 曲线画在同一张 ROOT 图中。横轴为深度 \(x\)，单位 mm；纵轴为 \(-dE/dx\)，单位 MeV/mm。横轴使用线性刻度。两条曲线量级相差较大时，纵轴使用对数刻度。

同一张图应有清楚的线型或颜色、粒子标识和坐标轴单位。两条曲线都应在约 127 mm 处终止，并在末端附近出现 Bragg 峰。

2. 准备 LISE++ 数据

按照前置教程，分别设置质子、水和 \(^{12}\mathrm{C}\)、水，导出射程和阻止本领数据。推荐在 LISE++ 中选择 micron，读入 ROOT 后统一换算为本作业使用的单位：

\[ R(\mathrm{mm})=\frac{R(\mu\mathrm{m})}{1000},\qquad S(\mathrm{MeV/mm})=1000\,S(\mathrm{MeV}/\mu\mathrm{m}). \]

记录所用 LISE++ 版本以及两种粒子各自选择的曲线名称。阻止本领和射程必须来自同一种模型；不要假定两个文件中编号相同的列一定对应同一种模型，也不要假定质子和碳离子应选择相同的曲线编号。

读入数据后，先画出或检查 \(R(\varepsilon)\) 和 \(S(\varepsilon)\)。交换射程数据的横、纵坐标，构造 \(\varepsilon(R)\)，并检查所用区间保持单调。数据范围必须覆盖产生 127 mm 射程所需的入射能量，并覆盖减速过程使用的低能区。TGraph::Eval 在数据范围外会继续外推，程序不会自动报告该结果缺少物理依据。

SRIM 可用于独立比较。SRIM 输出的 projected range 是沿初始方向的平均投影深度，不能直接代入下面的剩余射程法。若以 SRIM 为主，应从 stopping table 积分得到深度，并明确说明使用的 range 定义。

3. 三种计算方法

3.1 剩余射程法

由 \(R(\varepsilon)\) 交换横、纵坐标，构造单调区间内的反函数 \(\varepsilon(R)\)。目标射程对应的入射能量为

\[ \varepsilon_0=\varepsilon(R_{\mathrm{target}}),\qquad E_0=A\varepsilon_0. \]

粒子到达深度 \(x\) 后，剩余射程和能量为

\[ r(x)=R_{\mathrm{target}}-x,\qquad \varepsilon(x)=\varepsilon\bigl(r(x)\bigr). \]

在 \(0\leq x<R_{\mathrm{target}}\) 的一组深度点上计算 \(S(\varepsilon(x))\)，依次填入 TGraph；当剩余射程小于表格中的最小射程时停止，不在末端点外推。射程和阻止本领曲线应来自同一模型。这一方法作为另外两种离散积分方法的比较基准。

3.2 固定位置步长

设定位置步长 \(\Delta x\)，从 \(x_0=0\)、\(E_0=A\varepsilon_0\) 开始逐步更新：

\[ S_i=S(E_i/A),\qquad E_{i+1}=E_i-S_i\Delta x,\qquad x_{i+1}=x_i+\Delta x. \]

每一步把 \((x_i,S_i)\) 加入 TGraph。若最后一步会使能量变为负值，应缩短该步或在有效数据范围的末端停止；不要把负能量传给 TGraph::Eval。

以 \(^{12}\mathrm{C}\) 为例，至少选择三种逐步减小的位置步长，检查所得停止深度和曲线是否收敛。末端附近 \(S(E/A)\) 变化最快，固定步长产生的误差通常也最明显。

3.3 固定能量步长

设定每核子能量步长 \(\Delta\varepsilon>0\)。一次能量下降对应的总能量损失为 \(A\Delta\varepsilon\)，由此得到该步经过的厚度：

\[ \Delta x_i=\frac{A\Delta\varepsilon}{S(\varepsilon_i)},\qquad x_{i+1}=x_i+\Delta x_i,\qquad \varepsilon_{i+1}=\varepsilon_i-\Delta\varepsilon. \]

最后一步应使 \(\Delta\varepsilon\) 不超过当前的 \(\varepsilon_i\)。仍以 \(^{12}\mathrm{C}\) 为例，使用至少三种逐步减小的能量步长，检查停止深度和曲线的稳定性。

不要从 \(E=0\) 反向迭代。表格并未定义 \(S(0)\)，TGraph::Eval(0) 还可能成为外推。应先用射程反函数确定入射能量，再从入射端向前积分。

4. 数值检查

以 \(^{12}\mathrm{C}\) 为例比较三种方法，并检查以下结果：

  • 能量始终非负，所有插值点都在输入数据覆盖范围内；
  • 计算得到的停止深度随步长减小趋近 127 mm；
  • 对两种步进法，各步能量损失之和与入射总能量 \(E_0\) 一致，其差别与所采用的低能截止和最后一步处理相符；
  • 剩余射程法和两种离散积分法在数据有效范围内给出一致的曲线趋势。

在减小步长后，若停止深度或曲线仍出现系统差别，应先检查总能量与 \(E/A\)、μm 与 mm、MeV/μm 与 MeV/mm 的换算，再检查曲线模型和插值范围。

最后一个有效数据点之后不要人为添加同一深度处 \(S=0\) 的点。这样会在图上产生没有数值意义的竖直下降。接近停止点的最大值还会受到最低表格能量和采样密度影响，因此不能只用最后一个点的高度判断数值是否收敛。

5. 结果与讨论

Notebook 中应包含：

  • 输入数据和模型的说明，以及 \(R(\varepsilon)\)、\(\varepsilon(R)\)、\(S(\varepsilon)\) 的检查；
  • 质子和 \(^{12}\mathrm{C}\) 的 \(\varepsilon_0\)、\(E_0\) 及射程反查结果；
  • 两种粒子在相同射程下的 Bragg 曲线；
  • 以 \(^{12}\mathrm{C}\) 为例的三种计算方法比较和步长收敛检查；
  • 对下列物理与数值因素的说明：相同射程所需入射能量的差别、两种粒子阻止本领和 Bragg 峰的差别、三种方法之间的数值误差、低能数据边界对峰值的影响，以及本作业所忽略的物理过程。

6. Notebook 要求

可复用前置教程中的文本读取、TGraph 插值和反函数构造方法；Bragg 曲线生成及收敛检查应由自己完成。三种方法应写成可接收粒子参数和对应曲线的函数，最终图只保留收敛后的质子和 \(^{12}\mathrm{C}\) 两条曲线。把数据读取、单位换算、计算方法、画图和结果讨论分成含义清楚的代码与 Markdown 单元格。注释用于解释物理量、单位和不直观的计算步骤，不要求逐行翻译代码。

提交前重启内核并从第一格运行到最后一格，确认没有依赖未显示的旧变量或错误的执行顺序。
