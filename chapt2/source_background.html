源和本底测量时间的分配

本底需要单独测量。缩短本底测量时间不会改变本底率的期望值，却会增大扣除后的统计误差。

本底扣除

含源测量时间为 \(t_s\)，得到计数 \(N_{s+b}\)；本底测量时间为 \(t_b\)，得到计数 \(N_b\)。净计数率估计为

\[ \hat r_s=\frac{N_{s+b}}{t_s}-\frac{N_b}{t_b}. \]

两次测量相互独立并服从 Poisson 分布时，统计方差为

\[ \sigma^2_{\hat r_s} =\frac{N_{s+b}}{t_s^2}+\frac{N_b}{t_b^2}. \]

比较两种测量时间

下面保持含源测量时间 \(t_s=10\ \mathrm{s}\) 不变，分别取 \(t_b=t_s\) 和 \(t_b=t_s/10\)。代码只生成计数并计算净计数率及其统计误差。

TRandom3 rng(12345);

double sourceRate = 30.0;
double backgroundRate = 20.0;
double sourceTime = 10.0;
double backgroundTime[] = {10.0, 1.0};

for (double time : backgroundTime) {
    int sourceAndBackground = rng.Poisson(
        (sourceRate + backgroundRate) * sourceTime);
    int background = rng.Poisson(backgroundRate * time);

    double netRate = sourceAndBackground / sourceTime
                   - background / time;
    double error = sqrt(sourceAndBackground / (sourceTime * sourceTime)
                      + background / (time * time));

    std::cout << "background time = " << time
              << " s, net rate = " << netRate
              << " +/- " << error << " s^-1\n";
}

在这些设定下，使用期望计数估算可得：\(t_b=10\ \mathrm{s}\) 时误差约为 \(2.65\ \mathrm{s}^{-1}\)，而 \(t_b=1\ \mathrm{s}\) 时约为 \(5.00\ \mathrm{s}^{-1}\)。本底测量过短时，放大后的本底涨落会主导扣除结果。
