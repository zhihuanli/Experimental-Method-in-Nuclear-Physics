相邻事件时间间隔分布

在有限观测时间内均匀产生随机事件时刻，将这些时刻排序并作差，可以得到相邻事件的时间间隔。本教程从这一过程出发，验证时间间隔的指数规律，并由拟合恢复事件的平均计数率。

1. 在观测时间内均匀产生事件

若事件的平均计数率稳定，事件在观测时间 \(T\) 内没有偏好的位置。给定总事件数 \(n\)，每个事件时刻都可以由区间 \([0,T]\) 上的均匀分布产生，平均计数率为 \(r=n/T\)。

C++ ROOT

const double rate = 100.0;       // s^-1
const double duration = 1000.0; // s
const int n = static_cast<int>(rate * duration);

TRandom3 rng(20260906);
std::vector<double> times;
times.reserve(n);
TH1D eventTimes("eventTimes", "Event times;Time (s);Events per 10 s",
                100, 0.0, duration);

for (int i = 0; i < n; ++i) {
    double t = rng.Uniform(0.0, duration);
    times.push_back(t);
    eventTimes.Fill(t);
}

PyROOT

import ROOT

rate = 100.0       # s^-1
duration = 1000.0  # s
n = int(rate * duration)

rng = ROOT.TRandom3(20260906)
times = []
event_times = ROOT.TH1D(
    "event_times", "Event times;Time (s);Events per 10 s",
    100, 0.0, duration
)

for _ in range(n):
    t = rng.Uniform(0.0, duration)
    times.append(t)
    event_times.Fill(t)

在 \(T=1000\ \mathrm{s}\) 内均匀产生 \(10^5\) 个事件。各时间段的计数围绕均匀分布的期望值涨落。

这里固定总事件数 \(n\)，目的是从均匀的事件时刻验证时间间隔的结构。当 \(n\) 和 \(T\) 足够大且 \(n/T=r\) 保持不变时，观测区间内部的时间间隔趋近下面的指数分布。

2. 排序并计算相邻事件时间间隔

先将事件时刻按从小到大的顺序排列。对于一个远离观测边界的事件，其他 \(n-1\) 个均匀事件都不落入其后长度为 \(\tau\) 的时间段内的概率为

\[ P(\Delta t>\tau) =\left(1-\frac{\tau}{T}\right)^{n-1} \longrightarrow e^{-r\tau}. \]

对等待时间的累积分布求导，得到相邻事件时间间隔的概率密度：

\[ p(\Delta t)=r e^{-r\Delta t},\qquad E[\Delta t]=\frac{1}{r},\qquad \sigma_{\Delta t}=\frac{1}{r}. \]

C++ ROOT

std::sort(times.begin(), times.end());

TH1D h("h", "Adjacent events;#Deltat (s);Entries",
       120, 0.0, 12.0 / rate);
for (std::size_t i = 1; i < times.size(); ++i)
    h.Fill(times[i] - times[i - 1]);

TF1 f("f", "expo", 0.0, 8.0 / rate);
h.Fit(&f, "R");
double fittedRate = -f.GetParameter(1);

PyROOT

times.sort()

h = ROOT.TH1D("h", "Adjacent events;#Deltat (s);Entries",
              120, 0.0, 12.0 / rate)
for i in range(1, len(times)):
    h.Fill(times[i] - times[i - 1])

f = ROOT.TF1("f", "expo", 0.0, 8.0 / rate)
h.Fit(f, "R")
fitted_rate = -f.GetParameter(1)

ROOT 的 expo 表示 \(e^{p_0+p_1x}\)，所以当横轴单位为 s 时，计数率为 \(-p_1\)。若横轴单位为 μs，则计数率为 \(-10^6p_1\ \mathrm{s}^{-1}\)。GetParError(1) 给出斜率参数的拟合误差。

3. 每 \(N\) 个事件的时间间隔

记按时间排序的事件时刻为 \(t_i\)。相邻事件的间隔是 \(t_i-t_{i-1}\)；每 \(N\) 个事件的间隔定义为

\[ T_N=t_i-t_{i-N}. \]

\(T_N\) 是 \(N\) 个相邻时间间隔之和。将指数分布连续卷积 \(N\) 次可得

\[ p_N(t)=\frac{r^N t^{N-1}e^{-rt}}{(N-1)!},\qquad E[T_N]=\frac{N}{r},\qquad \sigma_{T_N}=\frac{\sqrt{N}}{r}. \]

因此，间隔包含的事件数增加时，分布不再从 \(t=0\) 单调下降，而是在有限时间处出现峰值。以 \(N=5\) 为例，只需在已经排序的事件时刻上填充 times[i] - times[i-5]：

// C++ ROOT
TH1D h5("h5", "Every 5 events;T_{5} (s);Entries",
        160, 0.0, 20.0 / rate);
for (std::size_t i = 5; i < times.size(); ++i)
    h5.Fill(times[i] - times[i - 5]);

# PyROOT
h5 = ROOT.TH1D("h5", "Every 5 events;T_{5} (s);Entries",
               160, 0.0, 20.0 / rate)
for i in range(5, len(times)):
    h5.Fill(times[i] - times[i - 5])

由均匀事件时刻得到相邻事件间隔。设定 \(r=100\ \mathrm{s}^{-1}\)，指数拟合得到 \(r=100.33\pm0.32\ \mathrm{s}^{-1}\)；右图使用同一计数率预测每 5 个事件的时间间隔。

4. 实验数据中的比较

固定时间窗内的平均计数除以时间窗长度，可以得到计数率；相邻事件时间间隔的指数拟合也可以得到计数率。两种结果应当在统计误差范围内一致。若存在明显差异，应回到数据随采集时间的变化，检查计数率是否稳定以及记录是否连续。
