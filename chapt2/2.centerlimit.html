中心极限定理

从同一分布独立抽样，比较一次测量与多次测量平均值的分布。

从均匀分布开始

设 \(x_i\) 相互独立，并服从区间 \([0,1]\) 上的均匀分布。一次实验取 \(m\) 个数并计算平均值

\[ \bar{x}=\frac{1}{m}\sum_{i=1}^{m}x_i. \]

重复许多次实验后，随着 \(m\) 增加，\(\bar{x}\) 的分布逐渐接近正态（Gaussian）分布。其均值保持为 \(1/2\)，标准差按

\[ \sigma_{\bar{x}}=\frac{1}{\sqrt{12m}} \]

减小。下面的代码直接比较 \(m=1,2,5,10,20\) 的结果。

TRandom3 rng(12345);

int m[] = {1, 2, 5, 10, 20};
TH1D *h[5];

for (int k = 0; k < 5; ++k) {
    h[k] = new TH1D(Form("h%d", m[k]),
                    Form("m = %d;sample mean;experiments", m[k]),
                    80, 0.0, 1.0);

    for (int experiment = 0; experiment < 100000; ++experiment) {
        double sum = 0.0;
        for (int i = 0; i < m[k]; ++i) {
            sum += rng.Uniform(0.0, 1.0);
        }
        h[k]->Fill(sum / m[k]);
    }
}

TCanvas c("c", "central limit theorem", 1000, 650);
c.Divide(3, 2);
for (int k = 0; k < 5; ++k) {
    c.cd(k + 1);
    h[k]->Draw();
}

适用条件

这里使用的均匀分布具有有限的均值和方差。中心极限定理并不直接适用于标准 Landau 分布，因为它没有有限的均值和方差；只有明确给出截断范围后，才可以研究截断分布的样本平均值。
