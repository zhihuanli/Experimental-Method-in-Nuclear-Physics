0. ROOT in interactive mode¶

The ROOT C++ kernel normally preloads common ROOT libraries. The explicit header files below document which classes are used and make the code easier to transfer to a macro or compiled program. Standard C++ headers provide console output, formatting, and mathematical utilities.

#include <iostream>
#include <iomanip>

#include <TROOT.h>
#include <TCanvas.h>
#include <TMath.h>
#include <TF1.h>
#include <TGraph.h>
#include <TRandom3.h>
#include <TH1.h>
#include <TH2.h>
#include <TFile.h>
#include <TFitResultPtr.h>

std::cout << "ROOT version: " << gROOT->GetVersion() << std::endl;

ROOT version: 6.40.00

#include <TF1.h> makes the declaration of TF1 available to the compiler; the other ROOT headers serve the same role. gROOT is ROOT's global application object. Only GetVersion() is needed here.

ROOT graphics can be displayed interactively in Jupyter with JSROOT. %jsroot on is a Jupyter command rather than a C++ statement and normally needs to be executed only once. If a local installation does not provide this command, skip the cell and use the configured display mode.

%jsroot on

Static HTML build: ROOT canvases are embedded as PNG images.

ROOT draws functions, graphs, and histograms on a TCanvas. The constructor used below is

TCanvas(name, title, width, height)

name is ROOT's internal name and should be unique within one session. title describes the canvas. width and height give its initial size in pixels.

new TCanvas(...) creates the object dynamically and returns its address. c1 is therefore declared as TCanvas*, a pointer to a TCanvas. A method is called through a pointer with ->, as in c1->Clear(). The same canvas is reused throughout the tutorial.

TCanvas *c1 = new TCanvas("c1", "ROOT Tutorial I", 800, 600);

ROOT mathematical functions are available in the TMath namespace. TMath::Sqrt(x) returns the square root of x, and TMath::Pi() returns pi. std::cout writes text and values to the cell output; std::endl ends the line.

double x0 = 2.0;
std::cout << "sqrt(2) = " << TMath::Sqrt(x0) << std::endl;
std::cout << "pi      = " << TMath::Pi() << std::endl;

sqrt(2) = 1.41421
pi      = 3.14159

A class defines a type of object; TCanvas and TF1 are classes. c1 points to one particular canvas. An operation belonging to an object is a method.

C++ uses two common method-call forms:

object.Method(arguments);     // object itself
pointer->Method(arguments);   // pointer to an object

Most ROOT examples create long-lived analysis objects with new and store pointers, so -> appears frequently. Ordinary local objects, such as the random-number generator used later, use .. A semicolon terminates a C++ statement.

1. TF1: one-dimensional functions¶

TF1 represents a mathematical function of one independent variable. In detector analysis it is commonly used for calibration curves and peak-shape or background models. A TF1 contains a formula and parameter values; it does not contain measured events.

The constructor used in this section is

TF1(name, formula, xmin, xmax)

name is the internal ROOT name, formula is a character string containing the expression, and xmin and xmax define the evaluation and drawing interval. The independent variable is written as x; adjustable parameters are [0], [1], and so on.

1.1 A linear calibration function¶

A detector and its electronics often produce an ADC channel rather than energy in keV. Over a suitable range, a first calibration model is frequently linear:

$$ E = a + b \times \text{channel}. $$

In the ROOT formula, [0] represents the offset a and [1] represents the gain b. The function below covers channels 0–4000.

TF1 *fcal = new TF1("fcal", "[0] + [1]*x", 0.0, 4000.0);
fcal->SetParNames("offset", "gain");
fcal->SetParameters(0.2, 0.5);
fcal->SetTitle("Linear calibration;Channel;Energy (keV)");

c1->Clear();
fcal->Draw();
c1->Draw();

SetParNames assigns labels to parameters [0] and [1]; it does not set their values. SetParameters(0.2, 0.5) assigns the offset and gain in that order, giving

$$ E = 0.2 + 0.5 \times \text{channel}. $$

A ROOT title string uses semicolons to separate the main title, x-axis title, and y-axis title. fcal->Draw() places the function on the current canvas, while c1->Draw() displays that canvas in Jupyter. No fit occurs because the parameter values were supplied directly.

Eval(value) applies the function at one value of the independent variable. It is useful for converting a channel after calibration coefficients have been determined.

double channel_test = 1500.0;
double energy_test = fcal->Eval(channel_test);
std::cout << "Channel " << channel_test
          << " -> Energy = " << energy_test << " keV" << std::endl;

Channel 1500 -> Energy = 750.2 keV

1.2 A Gaussian peak model¶

A Gaussian function is often used as a first approximation to the full-energy peak of a radiation detector:

$$ f(E)=A\exp\left[-\frac{1}{2}\left(\frac{E-\mu}{\sigma}\right)^2\right]. $$

The peak height A, centroid mu, and standard deviation sigma correspond to [0], [1], and [2]. The function is drawn over 400–700 keV.

TF1 *fpeak = new TF1(
    "fpeak",
    "[0]*exp(-0.5*((x-[1])/[2])^2)",
    400.0, 700.0
);
fpeak->SetParNames("height", "centroid", "sigma");
fpeak->SetParameters(1000.0, 550.0, 20.0);
fpeak->SetTitle("Gaussian peak model;Energy (keV);Counts");

c1->Clear();
fpeak->Draw();
c1->Draw();

The curve has height 1000 at 550 keV and width \(\sigma=20\) keV. For a Gaussian,

$$\mathrm{FWHM}=2\sqrt{2\ln 2}\,\sigma\approx2.355\sigma.$$

TF1 defines the curve; Sections 3 and 4 generate individual energies and fill a histogram.

2. TGraph: measured points¶

A TGraph stores pairs (x_i, y_i). It is appropriate when every point has a particular coordinate, such as a measured calibration-peak channel and its reference energy. A graph stores the supplied coordinates; it does not bin an axis or count repeated measurements.

2.1 Calibration points¶

Assume five gamma-ray peaks have been identified in an ADC spectrum. Their measured channel positions and reference energies are stored in two C++ arrays. n_cal gives the number of points and must agree with both array lengths.

const int n_cal = 5;
double ch[n_cal]   = {512.0, 1024.0, 1538.0, 2049.0, 2561.0};
double Eref[n_cal] = {122.1, 245.4, 367.8, 489.0, 612.3};

The constructor is

TGraph(number_of_points, x_values, y_values)

SetName assigns the internal ROOT name used when the graph is written to a file. SetMarkerStyle(20) selects a filled circular marker. In Draw("AP"), A creates axes and P draws points.

TGraph *gcal = new TGraph(n_cal, ch, Eref);
gcal->SetName("gcal");
gcal->SetTitle("Energy calibration;Channel;Energy (keV)");
gcal->SetMarkerStyle(20);

c1->Clear();
gcal->Draw("AP");
c1->Draw();

2.2 Fit the graph¶

The built-in ROOT formula pol1 is a first-degree polynomial:

$$ f(x)=[0]+[1]x. $$

The function flin covers channels 0–3000. gcal->Fit(flin, "RS") fits the points. R restricts the fit to the TF1 range; S returns a TFitResultPtr containing detailed fit information. The function is also attached to the graph and drawn with it.

TF1 *flin = new TF1("flin", "pol1", 0.0, 3000.0);
flin->SetParNames("offset", "slope");

TFitResultPtr calibration_fit = gcal->Fit(flin, "RS");
c1->Draw();

GetParameter(i) retrieves fitted parameter i. Parameter 0 is the offset in keV, and parameter 1 is the slope in keV/channel. The units follow from the graph axes; ROOT does not infer physical units from the numbers.

double fitted_offset = flin->GetParameter(0);

TGraph fits these points with equal weights. When the measured points have uncertainties, use TGraphErrors; see weighted fits and propagated errors.

2.3 Filling a TGraph point by point¶

A graph can also be created empty and filled with SetPoint(index, x, y). The index starts at zero. This form is useful when points are calculated one at a time inside a loop.

TGraph *g2 = new TGraph();
g2->SetName("g2");

for (int i = 0; i < n_cal; ++i) {
    g2->SetPoint(i, ch[i], Eref[i]);
}

g2->SetTitle("Calibration graph filled with SetPoint;Channel;Energy (keV)");
g2->SetMarkerStyle(21);

c1->Clear();
g2->Draw("AP");
c1->Draw();

The loop uses indices 0 through 4. At each index, matching elements of the channel and energy arrays are added as one point. Marker style 21 is a filled square. The numerical points are the same as in gcal; only the construction method and marker style differ.

2.4 Interpolate a table

TGraph.Eval(x) uses linear interpolation between neighbouring points by default. Unlike TF1.Eval(x), it evaluates the point data, not the fitted function. This is useful for stopping-power and range tables.

std::cout << "Interpolated energy = " << gcal->Eval(1000.0) << " keV" << std::endl;

Interpolated energy = 239.62 keV

A two-column text table can be read with TGraph table("range.txt", "%lg %lg");: the first selected column is x, the second y. Check the column units and use the tabulated range; choose a suitable interpolation when the values vary rapidly.

3. TRandom3: random sampling

Use Gaus for a Gaussian measurement fluctuation, Uniform for uniformly distributed values, and Poisson for a count in a fixed duration. All three methods use the same random-number generator.

The constructor is

TRandom3(seed)

The seed sets the initial generator state. A fixed positive seed reproduces the same sequence when the object is recreated. A different seed gives different samples from the same distributions.

Here rng is an ordinary C++ object rather than a pointer, so its methods use .. Rndm() takes no argument and returns one sample uniformly distributed between 0 and 1.

TRandom3 rng(12345);

for (int i = 0; i < 5; ++i) {
    std::cout << "sample " << i << ": " << rng.Rndm() << std::endl;
}

sample 0: 0.929616
sample 1: 0.890155
sample 2: 0.316376
sample 3: 0.130707
sample 4: 0.183919

Recreate the generator with the same positive seed to reproduce its sequence.

3.1 Gaussian smearing: detector resolution¶

Suppose monoenergetic radiation deposits a true energy of 548 keV. Finite detector resolution makes repeated measurements fluctuate around that value.

rng.Gaus(mean, sigma)

returns one Gaussian sample. mean is the center and sigma is the standard deviation; both have the same unit as the result. Gaus(548.0, 8.0) therefore represents one possible measured energy in keV.

double E_true = 548.0;   // keV
double sigma_E = 8.0;    // keV

for (int i = 0; i < 10; ++i) {
    double E_measured = rng.Gaus(E_true, sigma_E);
    std::cout << "measurement " << i << ": "
              << E_measured << " keV" << std::endl;
}

Each call represents one measurement of the same true energy. The ten results are not ten different gamma-ray energies. The Gaussian approximation isolates resolution; a complete detector response may contain additional components.

3.2 Uniform background¶

rng.Uniform(xmin, xmax)

returns a real number between xmin and xmax. The example assigns equal probability density to every energy between 0 and 2000 keV. The flat component demonstrates how distributions are combined; it is not a physical model of a general gamma-ray continuum.

for (int i = 0; i < 10; ++i) {
    double E_background = rng.Uniform(0.0, 2000.0);
    std::cout << "background sample " << i << ": "

3.3 Poisson fluctuation¶

For independent events occurring at a constant average rate, the count in a fixed interval is often modeled by a Poisson distribution.

rng.Poisson(mean_count)

takes the expected count in one interval and returns an integer. The argument is not an upper limit. For a Poisson distribution, the variance equals the mean, so the standard deviation is sqrt(mean_count).

double mean_count = 10.0;  // 10 Hz measured for 1 s
for (int i = 0; i < 10; ++i) {
    std::cout << rng.Poisson(mean_count) << std::endl;
}

4. TH1: one-dimensional histograms¶

A histogram represents the distribution of many measured or simulated values. Its horizontal axis is divided into bins. Fill(value) finds the bin containing value and increments that bin content by one. The histogram retains bin counts rather than the complete list of original values.

TH1 is the base class. The example uses TH1F; F means that bin contents are stored as single-precision floating-point values. TH1D is the corresponding double-precision class. Either is sufficient for the event counts used here.

4.1 Build a simple energy spectrum¶

The constructor is

TH1F(name, title, number_of_bins, xmin, xmax)

The histogram below has 400 bins from 0 to 2000 keV, so each bin is 5 keV wide. Values outside the range enter underflow or overflow bins.

The model contains 30,000 events in a 548-keV peak, 18,000 events in a 1250-keV peak, and 30,000 flat-background events. The two peaks use different sigma values. It is a simplified detector spectrum whose purpose is to combine random samples and histogram operations.

TH1F *hspec = new TH1F(
    "hspec",
    "Simulated energy spectrum;Energy (keV);Counts per 5 keV",
    400, 0.0, 2000.0
);

TRandom3 r1(24680);

for (int i = 0; i < 30000; ++i) {
    hspec->Fill(r1.Gaus(548.0, 10.0));
}
for (int i = 0; i < 18000; ++i) {
    hspec->Fill(r1.Gaus(1250.0, 18.0));
}
for (int i = 0; i < 30000; ++i) {
    hspec->Fill(r1.Uniform(0.0, 2000.0));
}

c1->Clear();
hspec->Draw();
c1->Draw();

Each loop adds one spectrum component. One iteration generates one energy and passes it to Fill. The number of iterations controls the number of events in that component, not the maximum bin height, because peak events are spread among several bins. Draw() without an option uses ROOT's default one-dimensional histogram style.

4.2 Inspect the histogram¶

GetEntries() returns the number of Fill calls, including underflow and overflow entries. GetMean() and GetStdDev() describe the complete distribution. GetNbinsX() gives the number of ordinary x bins, and GetBinWidth(1) gives the width of bin 1.

std::cout << "Entries     = " << hspec->GetEntries() << std::endl;
std::cout << "Number bins = " << hspec->GetNbinsX() << std::endl;
std::cout << "Bin width   = " << hspec->GetXaxis()->GetBinWidth(1)
          << " keV" << std::endl;
std::cout << "Mean        = " << hspec->GetMean() << " keV" << std::endl;
std::cout << "Std dev         = " << hspec->GetStdDev() << " keV" << std::endl;

Entries     = 78000
Number bins = 400
Bin width   = 5 keV
Mean        = 882.077 keV
Std dev         = 456.857 keV

The expected entries are 30000 + 18000 + 30000 = 78000. The mean and Std dev refer to the two peaks and background together; they are not the centroid and resolution of either peak. Individual peak properties require a selected region or a fit.

4.3 Fit one peak

The first peak lies on a flat background. Fit it over 500–600 keV using gaus(0)+pol0(3): parameters 0, 1, and 2 are the Gaussian height, mean, and sigma; parameter 3 is the constant background.

SetParameters supplies initial estimates. Read the approximate height, position, width, and background from the spectrum to start the numerical fit near the observed peak. SetParLimits below keeps the height, sigma, and background positive.

TF1 *fit_peak_548 = new TF1("fit_peak_548", "gaus(0)+pol0(3)", 500, 600);
fit_peak_548->SetParNames("height", "mean", "sigma", "background");
fit_peak_548->SetParameters(6000, 548, 10, 75);
fit_peak_548->SetParLimits(0, 0, 100000);
fit_peak_548->SetParLimits(2, 0.1, 40);
fit_peak_548->SetParLimits(3, 0, 10000);

Use Fit(..., "LIRS"). L selects a binned Poisson likelihood for the counts; I averages the model over each bin instead of using only its centre; R uses the function range; S returns the fit result. Zoom in with SetRangeUser to inspect the peak and its background.

TFitResultPtr peak_fit_result = hspec->Fit(fit_peak_548, "LIRS");
hspec->GetXaxis()->SetRangeUser(500, 600);
hspec->Draw("E");
c1->Draw();

GetParameter(i) retrieves a fitted value; GetParError(i) gives its fit uncertainty. Compare the fitted sigma with the input value, 10 keV.

A residual is the observed count minus the fitted expected count in the same bin. FindBin converts an axis coordinate to its bin number; ordinary histogram bins start at 1. Since the fit used I, obtain the expectation with Integral(low, high)/bin_width. A structured residual can reveal a missing component even when the overlaid curve looks acceptable.

TGraph *residual = new TGraph();
for (int b = hspec->FindBin(500); b < hspec->FindBin(600); ++b) {
    double lo = hspec->GetBinLowEdge(b);
    double width = hspec->GetBinWidth(b);
    double expected = fit_peak_548->Integral(lo, lo+width)/width;
    residual->SetPoint(residual->GetN(), hspec->GetBinCenter(b), hspec->GetBinContent(b)-expected);
}
residual->SetTitle("Fit residual;Energy (keV);Observed - fitted counts");
residual->SetMarkerStyle(20);
c1->Clear();
residual->Draw("AP");
c1->Draw();

4.4 Axis ranges and logarithmic scales

SetRangeUser changes the displayed x range. SetLogy() enables a logarithmic y axis; SetLogy(0) restores a linear axis. SetLogx() works similarly for a positive x range, as used for the Bragg curve. The commands below restore the full spectrum without changing its bin contents.

hspec->GetXaxis()->SetRange(0, 0);  // Restore the full x axis
c1->Clear();
c1->SetLogy();
hspec->Draw();
c1->Draw();

5. TH2: two-dimensional histograms¶

A two-dimensional histogram bins pairs of values. In detector analysis, the two quantities should belong to the same measurement or event. Typical applications include beam-position maps, two detector signals, and particle-identification plots.

TH2 is the base class. The example uses TH2F, whose bin contents use single-precision floating-point storage.

5.1 Beam spot on a detector plane¶

Suppose a position-sensitive detector reports x and y for every particle. The constructor is

TH2F(name, title, nx, xmin, xmax, ny, ymin, ymax)

The x axis has nx bins from xmin to xmax, and the y axis is analogous. Both axes below have 120 bins from -30 to 30 mm, giving 0.5-mm bins.

c1->SetLogy(0);
TH2F *hxy = new TH2F(
    "hxy",
    "Beam spot on detector plane;x (mm);y (mm)",
    120, -30.0, 30.0,
    120, -30.0, 30.0
);

TRandom3 r2(13579);

for (int i = 0; i < 50000; ++i) {
    double x_position = r2.Gaus(2.0, 6.0);
    double y_position = r2.Gaus(-1.0, 4.0);
    hxy->Fill(x_position, y_position);
}

c1->Clear();
hxy->Draw("COLZ");
c1->Draw();

Gaus(2.0, 6.0) gives an x distribution with mean 2 mm and sigma 6 mm. Gaus(-1.0, 4.0) gives a y distribution with mean -1 mm and sigma 4 mm. One loop iteration produces one (x, y) pair, entered with Fill(x, y).

In Draw("COLZ"), COL represents bin contents by color and Z adds a color scale. Here x and y are sampled independently. A TH2 displays their joint distribution; its use alone does not establish physical correlation.

std::cout << "Entries = " << hxy->GetEntries() << std::endl;
std::cout << "Mean x  = " << hxy->GetMean(1) << " mm" << std::endl;
std::cout << "Mean y  = " << hxy->GetMean(2) << " mm" << std::endl;
std::cout << "Std dev x   = " << hxy->GetStdDev(1) << " mm" << std::endl;
std::cout << "Std dev y   = " << hxy->GetStdDev(2) << " mm" << std::endl;

Entries = 50000
Mean x  = 2.02314 mm
Mean y  = -1.00589 mm
Std dev x   = 6.02503 mm

For a TH2, axis number 1 refers to x and axis number 2 to y. The calculated means and Std dev values should approach the generation parameters. A real beam-profile analysis would fill measured positions; the histogram operations would be unchanged.

5.2 Project onto one axis

ProjectionX sums the 2D bin contents along y; ProjectionY sums along x. They produce one-dimensional histograms without generating new events.

TH1D *px = hxy->ProjectionX("px");
TH1D *py = hxy->ProjectionY("py");
c1->Clear();
c1->Divide(2, 1);
c1->cd(1); px->Draw();
c1->cd(2); py->Draw();
c1->Draw();

For a selected band of y bins, use ProjectionX("name", first_y_bin, last_y_bin). Both endpoints are included. Convert a coordinate to its bin number with GetYaxis().FindBin(value) (C++: GetYaxis()->FindBin(value)).

6. TFile: save and reload ROOT objects¶

A TFile is a ROOT object container. It stores graphs, histograms, functions, and other ROOT objects under ROOT names. Writing an object differs from saving a plot image: a ROOT file preserves the numerical object for another analysis session.

6.1 Write objects to a ROOT file¶

The constructor has a filename and access mode:

TFile(filename, mode)

RECREATE creates a file and overwrites an existing file with the same name. READ opens an existing file without modifying it. UPDATE permits reading and writing while preserving existing contents.

fout->cd() makes fout the current ROOT directory. Each object's Write() method stores it under its internal ROOT name. Close() finishes writing and closes the file.

TFile *fout = new TFile("root_tutorial1.root", "RECREATE");
fout->cd();

gcal->Write();
hspec->Write();
hxy->Write();

fout->Close();

The file contains objects named gcal, hspec, and hxy. The C++ variable holding a pointer and the internal ROOT object name are separate, although using similar names is convenient. The stored name comes from the constructor or SetName.

6.2 Open the file and inspect its contents

Open reads the file just written; ls() lists its objects. If opening a supplied data file fails, check its name and location before continuing.

TFile *fin = TFile::Open("root_tutorial1.root", "READ");
fin->ls();

TFile**		root_tutorial1.root
 TFile*		root_tutorial1.root
  KEY: TGraph	gcal;1	Energy calibration
  KEY: TH1F	hspec;1	Simulated energy spectrum
  KEY: TH2F	hxy;1	Beam spot on detector plane

6.3 Read back one object

GetObject("hspec", hread) retrieves the histogram by its stored ROOT name and assigns its pointer to hread.

TH1F *hread = nullptr;
fin->GetObject("hspec", hread);
c1->Clear();
hread->Draw();
c1->Draw();

The three operations have distinct roles:

  • Draw() displays an object.
  • Write() stores an object in the current output file.
  • GetObject() retrieves an object by its ROOT name.

Close the input file after the retrieved object is no longer needed. hread must not be used afterward unless the histogram is read again or detached from the file.

if (fin) fin->Close();

Summary¶

TF1 represents a one-dimensional model. TGraph stores coordinate pairs. TRandom3 supplies pseudo-random samples from distributions selected through Gaus, Uniform, and Poisson. TH1F and TH2F accumulate one- and two-dimensional distributions, and TFile stores ROOT objects.

The C++ version also establishes several syntax distinctions:

  • an object uses . while a pointer to an object uses ->;
  • new creates a dynamically allocated object and returns a pointer;
  • :: accesses a namespace or a static class method, as in TMath::Pi() and TFile::Open();
  • a semicolon terminates a C++ statement, while braces group a loop, condition, or function body.
