Installing ROOT and JupyterLab

Set up a notebook that can draw a ROOT plot and read and write a ROOT file. These checks cover the environment used in the course assignments.

PyROOT uses ROOT from Python; ROOT C++ uses it from C++. JupyterLab provides the notebook interface. Choose one language for your work; both use the same ROOT objects and files.

If you already have a working ROOT notebook or use the course Jupyter service, go directly to the notebook checks. A new local installation below uses Miniforge on Linux, macOS, or Ubuntu under Windows WSL2.

1. Prepare the terminal

Linux users continue to Section 2. On macOS, use the normal terminal; if Apple's Command Line Tools are not installed, run xcode-select --install and complete the installer first.

On Windows 10 (version 2004 or later) or Windows 11, open PowerShell as Administrator and install Ubuntu:

wsl --install -d Ubuntu

Restart if requested, open Ubuntu from the Start menu, and create a Linux user name and password. Check the installation in PowerShell:

wsl --list --verbose

The Ubuntu row should show version 2. If it shows 1, run wsl --set-version Ubuntu 2. Enter the remaining commands in the Ubuntu terminal, not PowerShell.

2. Install ROOT and JupyterLab

Install Miniforge

On Ubuntu, first install the download tools. Skip these two commands on macOS:

sudo apt update
sudo apt install -y curl ca-certificates

Download the installer for your operating system and processor:

mkdir -p ~/Downloads
cd ~/Downloads
curl -L -O "https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-$(uname)-$(uname -m).sh"
bash "Miniforge3-$(uname)-$(uname -m).sh"

Keep the default installation directory and answer yes to initialize conda. Close and reopen the terminal, then run conda --version.

Install the course packages

conda config --set channel_priority strict
conda config --set auto_activate_base true
conda install -n base -c conda-forge root jupyterlab notebook ipykernel metakernel numpy

ROOT supplies the analysis classes and PyROOT interface; NumPy supplies numerical arrays. The remaining packages provide Jupyter and its Python and ROOT C++ notebook support. No separate RooFit installation is needed.

This setup uses Miniforge's default base environment, loaded automatically in a new terminal. Keep an existing working installation if you have one; avoid mixing ROOT, Python, and Jupyter from different installations.

3. Start a notebook

mkdir -p ~/experimental-methods
cd ~/experimental-methods
jupyter lab --no-browser

Open the address printed in the terminal in your browser, including its token. Under WSL, use the Windows browser. Keep the terminal open while working.

In JupyterLab, open a folder for the current assignment. Click + and select Python 3 for PyROOT or ROOT C++ for C++. An HTML course page is for reading; create an .ipynb notebook to run its examples, or open a supplied notebook.

  • Shift+Enter runs the current cell. Change its type to Markdown for text and equations.
  • Kernel → Interrupt Kernel stops a running calculation.
  • Kernel → Restart Kernel and Run All Cells runs the notebook from a clean state. Saving a notebook does not save the variables in kernel memory.
  • Save with Ctrl+S (⌘+S on macOS). To stop JupyterLab, press Ctrl+C in its terminal.

4. Check graphics and ROOT files

Run the cells below in the language you selected. %jsroot on enables interactive plots in Jupyter; it is not a command for a Python script or a C++ source file.

import ROOT
print(ROOT.gROOT.GetVersion())
%jsroot on

Create a histogram and display it on a canvas:

c = ROOT.TCanvas("c", "Installation check", 600, 400)
h = ROOT.TH1F("h", "Test histogram;x;Counts", 20, 0, 10)
h.Fill(4.5)
h.Draw()
c.Draw()

Write it to a test file, reopen the file, and read the histogram:

fout = ROOT.TFile("root_check.root", "RECREATE")
h.Write()
fout.Close()

fin = ROOT.TFile.Open("root_check.root")
fin.ls()
hread = fin.Get("h")
print("Entries:", hread.GetEntries())
fin.Close()
#include <iostream>
#include <TROOT.h>
#include <TCanvas.h>
#include <TH1.h>
#include <TFile.h>
std::cout << gROOT->GetVersion() << std::endl;
%jsroot on

Create a histogram and display it on a canvas:

TCanvas *c = new TCanvas("c", "Installation check", 600, 400);
TH1F *h = new TH1F("h", "Test histogram;x;Counts", 20, 0, 10);
h->Fill(4.5);
h->Draw();
c->Draw();

Write it to a test file, reopen the file, and read the histogram:

TFile *fout = new TFile("root_check.root", "RECREATE");
h->Write();
fout->Close();

TFile *fin = TFile::Open("root_check.root");
fin->ls();
TH1F *hread = nullptr;
fin->GetObject("h", hread);
std::cout << "Entries: " << hread->GetEntries() << std::endl;
fin->Close();

You should see a histogram with one filled bin, a file listing containing h, and Entries: 1 (or 1.0). RECREATE overwrites a file of the same name: use it for your output, not the supplied experimental data.

5. Prepare assignment files

Keep each notebook and its input data in the same assignment folder. For example:

coursework3.1/
    analysis.ipynb
    gamma.root

Download gamma.root from the HPGe assignment. The PSD assignment similarly uses liquidpsd_tree.root. Upload or copy the data file into the notebook folder, then open it using the filename shown in the example. Keep generated output under a different filename.

For the Bragg curve and the telescope simulation, also keep exported stopping-power and range tables alongside the notebook. LISE++ or SRIM is used to obtain these tables; follow the energy-loss example for their use.

Under WSL, open the current Ubuntu directory in Windows File Explorer with explorer.exe ., then copy the files there. JupyterLab also has an upload button.

Daily startup

cd ~/experimental-methods
jupyter lab --no-browser

Open the assignment folder and its notebook. Tutorial I introduces the ROOT operations used in assignments 1–3; Tutorial II adds the TTree methods used in assignments 4.1 and 5.1.

6. Troubleshooting

  • import ROOT fails or the ROOT C++ kernel is missing: check the paths and kernels in the terminal below. For this Miniforge setup, ROOT, Python, and Jupyter should come from the same miniforge3 installation.
  • No plot: call c.Draw() or c->Draw() after drawing the object. If the interactive display fails, try %jsroot off for a static image.
  • Data file not found: check the notebook folder and the exact filename, including upper- and lower-case letters. fin.ls() lists objects inside a successfully opened ROOT file.
which root
which python
which jupyter
root-config --version
python -c 'import ROOT; print(ROOT.gROOT.GetVersion())'
jupyter kernelspec list

If you need help, include the failed command and its error message. Do not share the Jupyter token URL.
