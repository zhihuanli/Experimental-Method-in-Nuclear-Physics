Installing ROOT and JupyterLab

Complete the tasks on this page before beginning the Python, C++, or ROOT tutorials. The supported setup is native Linux or Windows 10/11 with Ubuntu under WSL2.

ROOT is a C++ data-analysis framework. PyROOT provides access to the same ROOT classes from Python. JupyterLab is the browser interface used for the course notebooks. Each notebook uses a kernel: Python 3 for PyROOT or ROOT C++ for C++.

Miniforge is used once to install compatible versions of ROOT, Python, and Jupyter in its default installation. That installation is loaded automatically when a terminal opens. Students do not need to create, select, or activate a separate environment.

Tasks

  1. Prepare Windows with WSL2
  2. Install ROOT and Jupyter
  3. Verify ROOT and both kernels
  4. Learn the Jupyter essentials
  5. Use the daily startup routine
  6. Diagnose installation problems

Task 1. Prepare Windows with WSL2

Native Linux users continue directly to Task 2. Windows users open PowerShell as Administrator and enter:

Administrator PowerShell

wsl --install -d Ubuntu

Restart Windows, open Ubuntu from the Start menu, and create the requested Linux user name and password. The password is not displayed while it is typed.

Check the WSL version in PowerShell:

wsl --list --verbose

The Ubuntu row must show version 2. If it shows version 1, use the distribution name printed by the preceding command:

wsl --set-version Ubuntu 2

All commands in the remaining tasks are entered in the Ubuntu terminal or a native Linux terminal, not in PowerShell.

Task 2. Install ROOT and Jupyter

Install Miniforge

On Ubuntu or Debian, install the download tools:

sudo apt update
sudo apt install -y curl ca-certificates

Download and run the Miniforge installer:

mkdir -p ~/Downloads
cd ~/Downloads
curl -L -O "https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-$(uname)-$(uname -m).sh"
bash "Miniforge3-$(uname)-$(uname -m).sh"

Accept the licence, keep the default installation path, and answer yes when the installer asks whether to initialize conda. Close and reopen the terminal, then check:

conda --version

If the command is not found, enter the following two commands and reopen the terminal once more:

source ~/miniforge3/etc/profile.d/conda.sh
conda init bash

On a non-Debian Linux distribution, install curl and CA certificates with its package manager; the Miniforge commands remain the same.

Install the course software

conda config --set channel_priority strict
conda config --set auto_activate_base true
conda install -n base -c conda-forge root jupyterlab notebook metakernel numpy

Enter y when conda asks to proceed. The download can take several minutes and requires several gigabytes of free space. Close and reopen the terminal after installation. The optional (base) at the beginning of the prompt means the course software is ready; no activation command is required.

Use this as the single course installation. Do not create another conda environment or install another ROOT with apt, Snap, or pip. Do not add sudo to conda or Jupyter commands.

Task 3. Verify ROOT and both kernels

Run the complete check in the same terminal:

which root
which python
which jupyter
root-config --version
python -c 'import ROOT; print(ROOT.gROOT.GetVersion())'
jupyter kernelspec list

Continue only when all three conditions are satisfied:

  1. The paths printed by which belong to miniforge3/bin.
  2. root-config and PyROOT both print a ROOT version.
  3. The kernel list contains Python 3 and ROOT C++.

If a condition fails, keep the complete terminal output and use the diagnostic procedure in Task 6. Do not try several unrelated installation recipes in succession.

Task 4. Learn the Jupyter essentials

Start JupyterLab

mkdir -p ~/experimental-methods
cd ~/experimental-methods
jupyter lab --no-browser

Copy the complete address printed in the terminal, including its token, into a browser. Under WSL, use the normal Windows browser. Keep the terminal open while JupyterLab is running.

Check a Python notebook

Click the + button to open the Launcher and select Python 3. Enter the following code in the first cell and press Shift+Enter:

import ROOT
print(ROOT.gROOT.GetVersion())

Check a C++ notebook

Open another Launcher, select ROOT C++, and run:

#include <iostream>
#include <TROOT.h>

std::cout << gROOT->GetVersion() << std::endl;

Both cells should print the same ROOT version. ROOT objects and %jsroot on are introduced with their experimental context in ROOT Tutorial I rather than on this installation page.

Operations used throughout the course

  • Shift+Enter: run the current cell and move to the next one.
  • Toolbar cell-type menu: change a Code cell to Markdown for explanations and equations.
  • Kernel → Interrupt Kernel: stop a cell that does not finish.
  • Kernel → Restart Kernel and Run All Cells: clear the session and verify that the notebook runs in order.
  • Ctrl+S: save the notebook.

A saved notebook stores code, Markdown, and outputs, but not the live variables in kernel memory. Reopen the notebook and run its cells again. Use the course HTML page in a separate browser tab while reproducing or modifying its code in JupyterLab.

To stop JupyterLab, return to its terminal and press Ctrl+C. Closing the browser tab alone does not stop the server.

Task 5. Use the daily startup routine

Miniforge loads the course software automatically in each new terminal. The daily startup is:

cd ~/experimental-methods
jupyter lab --no-browser

No conda activate command is needed.

Under WSL, keep active analysis files in ~/experimental-methods. Open the current Linux directory in Windows File Explorer with:

explorer.exe .

Windows files are also visible under /mnt/c/Users/..., but repeatedly analysing data across the Windows/Linux file-system boundary can create path and performance problems.

Task 6. Diagnose installation problems

If a check in Task 3 fails, collect the environment information before changing the installation:

uname -a
conda info
conda list root
which root
which python
which jupyter
root-config --version
python --version
jupyter --version
jupyter kernelspec list

Compare the paths, ROOT versions, and kernel list with the three conditions in Task 3. When asking an instructor or a diagnostic tool for help, include the failed command and its complete text output. Do not share passwords or Jupyter token URLs. After changing the installation, rerun the full check in Task 3.

Continue with the course tutorials

After Task 3 succeeds and both test notebooks print the ROOT version, continue through one language path:

  • Python: Python Essentials for PyROOT, then ROOT Tutorial I and ROOT Tutorial II.
  • C++: C++ Basics for ROOT and C++ Objects and Pointers for ROOT, then ROOT Tutorial I and ROOT Tutorial II.
